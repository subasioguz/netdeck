# Netdeck brand

- **Name:** write "Netdeck" (one word, capital N). Never "NetDeck" or "Net Deck". Lowercase `netdeck` only in identifiers, URLs and CLI names.
- **Mark:** "Patch N", the letter N drawn as one patch cable with an RJ-45 plug at each end.
  - `netdeck-mark.svg`: one color (`currentColor`), 24 px and up.
  - `netdeck-mark-small.svg`: 16-23 px, heavier cable, no plug contacts.
  - `netdeck-app-logo.svg`: the 28 pt sidebar logo (white mark on an Ink square, radius 8; inverted in dark mode).
- **Colors:** Ink `#111114` (mark, primary button), Signal Blue `#2F6BFF` (app icon, accent), Frame `#EBEBEE`, Surface `#FFFFFF`. All are app tokens from `docs/DESIGN.md` §1. Never put the mark in VLAN, green, red or amber colors.
- **Clear space:** x = width of the mark; keep 1x clear on every side. Minimum size: mark 16 px, horizontal lockup 96 px wide.
- **Type:** SF Pro in the app; Geist SemiBold (SIL OFL 1.1) for marketing headlines.
- **App icon:** `Resources/AppIcon.icns`, built from the 1024 px master.
- **Masters:** the icon masters, boards and full brand guide live in the design working folder outside this repository (`netdeck-design/brand/`).
- The Netdeck name and logo are not covered by the Apache-2.0 license.
